# Smart Contracts Multi-Level Obfuscation (SolObfuscator)

A pure-Python, source-level multi-level obfuscator for Solidity smart contracts, shipped with an
automated test harness and a four-dimension quantitative evaluation pipeline
(**Potency**, **Stealth**, **Resilience**, **Cost**).

Course project for **HKUST CSIT5730 - Principles of Cybersecurity**.

> **Status: all five phases complete.**
> Environment, four benchmark contracts, the solc wrapper, the byte-patch engine, the three
> obfuscation levels, the batch CLI and the four-dimension evaluation with charts are implemented.
> All 16 contract variants pass the equivalence suite, and `eval/output/` holds the CSV, the four
> 300 DPI charts and the Dedaub bytecode dumps.

## 1. Motivation

Once deployed, a smart contract's EVM bytecode is public to the whole network, so a decompiler
such as Dedaub can recover most of the business logic. At the same time the EVM is extremely
sensitive to **gas consumption** and to the **24 KB runtime bytecode limit (EIP-170)**, so heavy
traditional obfuscation cannot be applied as-is. This project explores a *source-level*,
multi-level, low-overhead alternative with a strict equivalence guarantee.

## 2. Obfuscation levels

| Level | Pass (module) | Technique | Hard constraint |
| ----- | ------------- | --------- | --------------- |
| L1 | `obf/passes/layout.py` | Comment stripping, whitespace compaction, ABI-safe renaming of `private`/`internal` functions, parameters and locals | Public ABI must not change |
| L2 | `obf/passes/data.py` | Integer literals split with XOR: `(uint256(N ^ R) ^ uint256(R))`; boolean literals replaced by equivalent expressions | Type-safe under Solidity 0.8 checked arithmetic |
| L3 | `obf/passes/control.py` | Opaque predicates derived from runtime on-chain state (`block.timestamp`, `tx.gasprice`, `msg.sender`), side-effect-free dead branches | Must survive `solc --optimize`; no state mutation |

The obfuscated contract must keep **the same external ABI** and **100% identical business logic
and `revert` behaviour** as the original.

## 3. Environment

| Item | Requirement |
| ---- | ----------- |
| OS | Linux (Ubuntu VM) preferred; Windows / WSL2 supported with the cross-platform rules below |
| Python | **3.10 or 3.11** - do not use 3.12 / 3.13 (prebuilt wheels for `web3[tester]` crypto extensions) |
| Solidity compiler | `solc 0.8.20`, installed through `py-solc-x` and always passed explicitly to Slither |
| Chain sandbox | `web3[tester]` `EthereumTesterProvider` (py-evm), no external node, no network RPC |
| Not allowed | Node.js / Hardhat anywhere in the pipeline |

Cross-platform rules that are enforced by the code base:

* Every `.sol` file is normalised to **LF** before compiling or patching; solc AST offsets are UTF-8
  **byte** offsets, so string and bytes views must come from the same normalised source.
* All path handling uses `pathlib.Path`; no hardcoded separators.
* CLI logs, tables and matplotlib labels are **plain ASCII English** (Windows PowerShell defaults to
  GBK and would otherwise raise `UnicodeEncodeError`).

## 5. Testing

```bash
# baseline: the four original contracts, default solc settings
.venv/bin/python -m pytest tests/ -v

# same suite with solc --optimize (DoD requires both compiler settings)
.venv/bin/python -m pytest tests/ -v --optimize

# run the identical suite against an obfuscated variant directory
.venv/bin/python -m pytest tests/ -v --contract-dir eval/output/obfuscated/L3
# equivalent: OBF_CONTRACT_DIR=eval/output/obfuscated/L3 .venv/bin/python -m pytest tests/ -v
```

* `tests/test_equivalence.py` (41 tests) covers all four contracts: state changes, emitted
  events and revert boundaries (unauthorised callers, wrong state, insufficient
  allowance/balance, time checks), plus the optimizer matrix, CRLF/LF equality and
  compilation determinism.
* `tests/test_engine.py` (30 tests) covers the patch engine: LF normalisation of `\r\n`
  and lone `\r`, `src` parsing, AST walking with ancestor chains, UTF-8 byte-offset
  robustness against non-ASCII comments, insertion/deletion patches, overlap and
  range rejection, deterministic seeds, per-pass recompilation and error attribution.
* `tests/test_passes.py` (22 tests) covers the three levels: comment stripping keeps
  SPDX and string literals, only non-ABI symbols are renamed, uint256 literals are XOR
  split while narrow integers are left alone, booleans become byte comparisons, `pure`
  functions and declaration statements are never wrapped, the injection budget is
  respected, every level keeps the ABI JSON identical, and an obfuscated ERC20 still
  charges the right fee when deployed on py-evm.
* `tests/test_cli.py` (7 tests) covers `python -m obf.cli`: `--all-levels` writes 12 files,
  the report stays ASCII, the same seed reproduces identical bytes, single-file mode
  writes LF-only UTF-8, and invalid usage or a missing input exits with the documented code.
* `tests/test_eval.py` (12 tests) covers the evaluation maths (cosine similarity, runtime
  block counting, retention ratio, AST counting), checks that every gas scenario still
  targets a real ABI function, and verifies the committed CSV shape and chart/bytecode
  artefacts.
* `--contract-dir` / `OBF_CONTRACT_DIR` switch the source directory, so Phase 3/4 can point the
  same suite at L1/L2/L3 outputs without touching test code.
* Every pytest run writes `tests/artifacts/gas_report.json` with deployment gas, per-function
  call gas and runtime bytecode size for each deployment; `eval/run_eval.py` performs its own
  fixed-scenario gas measurement so the CSV does not depend on a previous test run.

## 6. Command-line interface

```bash
# one level for the whole contracts/ directory -> <out>/L3/*.sol
python -m obf.cli -i contracts -o eval/output/obfuscated -l 3 --seed 42 --max-injections 2

# all three levels in one run -> <out>/L1/, <out>/L2/, <out>/L3/
python -m obf.cli -i contracts -o eval/output/obfuscated --all-levels --seed 42

# a single contract straight to a file
python -m obf.cli -i contracts/Counter.sol -o /tmp/Counter_L3.sol -l 3
```

The console report is plain ASCII so Windows PowerShell and Linux terminals agree:


* Directory input writes `<output>/L<level>/<Name>.sol`; `--all-levels` writes `L1`, `L2` and `L3`.
* Output is UTF-8 with LF newlines; `--seed` makes the run byte-for-byte reproducible.
* Exit code `0` on success, `1` if any file failed, `2` for invalid usage or a missing input.
* `--max-injections N` caps Level 3 injections per function (default 3, use 2 for tighter gas).
* `eval/output/obfuscated/` in this repository contains the current L1/L2/L3 output for
  `--seed 42`, so the 16-variant regression can be re-run without regenerating first.

## 7. Evaluation

```bash
.venv/bin/python eval/run_eval.py     # CSV + Dedaub bytecode dumps
.venv/bin/python eval/plot_charts.py  # four 300 DPI PNG charts
```

`run_eval.py` evaluates 4 contracts x 4 levels x 2 solc optimizer settings (32 rows) and writes
`eval/output/metrics_summary.csv`:

| Dimension | Columns | Measurement |
| --- | --- | --- |
| Potency | `ast_nodes`, `cfg_basic_blocks`, `cfg_edges` | AST recursion; Slither with the explicit solc 0.8.20 path, summed over non-constructor functions |
| Stealth | `opcode_cosine_sim` | cosine similarity of runtime opcode frequency vectors against the contract's own L0 |
| Resilience | `bytecode_diff_sim`, `optimizer_retention_rate` | difflib ratio of runtime bytecode hex; share of added runtime basic blocks (JUMPDEST markers) surviving `--optimize` |
| Cost | `bytecode_size_kb`, `deploy_gas`, `avg_exec_gas`, `*_delta_pct` | py-evm deployment plus a fixed core-call scenario per contract, relative to L0 |

`optimizer_retention_rate` is measured on deployed bytecode rather than Slither's CFG: the CFG is
rebuilt from the Solidity AST, so it is identical with and without `--optimize`, while the optimizer
can only delete code at the bytecode level. Levels 1 and 2 add no runtime blocks, so their retention
is undefined (empty cell) and the chart shows Level 3 only. See section 10 for why Level 2 barely
moves the optimized bytecode.

Charts (English labels, 300 DPI):

* `fig1_gas_overhead.png` - deployment and core-call gas growth per level, 4 contracts.
* `fig2_potency_complexity.png` - AST nodes and CFG blocks/edges vs level.
* `fig3_security_gas_tradeoff.png` - CFG growth (potency) vs call-gas growth (cost).
* `fig4_stealth_resilience_opt.png` - opcode cosine / bytecode diff similarity and Level 3 retention.

`SimpleERC20_L0_runtime_bytecode.txt` and `SimpleERC20_L3_runtime_bytecode.txt` contain plain hex
runtime bytecode for the Dedaub decompilation screenshots.

## 9. Acceptance criteria (Definition of Done)

* 16 contract variants (4 contracts x 4 levels) compile with `solc 0.8.20`, with and without
  `--optimize`.
* All 16 variants pass the same parameterised pytest suite; external ABI signatures identical.
* Same `--seed` yields byte-identical output across runs and across Windows / Linux.
* L3 opaque predicates and dead branches survive `solc --optimize` (CFG complexity retained).
* Every runtime bytecode stays below 24,576 bytes.
* One command produces the CSV summary plus four PNG charts in `eval/output/`.

## 10. Threat model and known limitations

* **Level 2 is weak under `solc --optimize`.** `(uint256(N ^ R) ^ uint256(R))` is a constant
  expression, so the optimizer can fold it away. Measured on the committed output: the
  optimized L2 bytecode of SimpleERC20 and SimpleAuction is the same size as L1, while Counter
  and EscrowVault keep only a 12 B / -2 B difference (solc 0.8.20 does not canonicalise every
  folded form at codegen level). This is a documented finding rather than a bug: the
  specification fixes this exact L2 template, and the anti-optimization acceptance criterion
  targets Level 3. A stronger variant could keep the mask in a private `immutable` salt at the
  cost of one storage slot and extra constructor work.
* **Opaque predicates resist the optimizer and decompilers, not SMT solvers.** The L3
  predicates cannot be constant-folded and they break pattern-based decompilation, but a
  symbolic-execution engine (Mythril, Z3) can constrain `block.timestamp & 1` and prune the
  branches. A predicate built from a hash of block data would raise that bar at a gas cost that
  is out of scope here.
* **Metric proxies.** `runtime_basic_blocks` counts `JUMPDEST` tokens in solc's disassembled
  opcode list (a PUSH payload is a separate token, so bytes inside push data can never be
  miscounted) and includes the function entry block. `bytecode_diff_sim` is a `difflib`
  character-level ratio, so relocated jump offsets move it strongly; it measures surface
  difference, not semantic similarity.
* **Source size is not runtime size.** L3 source grows with each injected dead-code snippet,
  and Counter has the most short functions, so it receives the most injections and ends up with
  the largest source file. Its runtime bytecode (5,068 B) is still smaller than SimpleERC20's
  (5,494 B) and far below the EIP-170 limit.

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

/// @title Counter
/// @notice Minimal permissioned counter used as a smoke-test and obfuscation target.
/// @dev Single file, no imports: the obfuscator pipeline compiles it standalone.
contract Counter {
    address public owner;
    uint256 public count;
    bool public paused;

    event CountChanged(address indexed caller, uint256 newValue);
    event PausedChanged(bool paused);
    event OwnershipTransferred(address indexed previousOwner, address indexed newOwner);

    constructor(uint256 initialValue) {
        owner = msg.sender;
        count = initialValue;
    }

    modifier onlyOwner() {
        require(msg.sender == owner, "Counter: caller is not the owner");
        _;
    }

    modifier whenNotPaused() {
        require(!paused, "Counter: paused");
        _;
    }

    function increment() external whenNotPaused returns (uint256) {
        count += 1;
        emit CountChanged(msg.sender, count);
        return count;
    }

    function decrement() external whenNotPaused returns (uint256) {
        require(count > 0, "Counter: underflow");
        count -= 1;
        emit CountChanged(msg.sender, count);
        return count;
    }

    function reset() external onlyOwner returns (uint256) {
        count = 0;
        emit CountChanged(msg.sender, count);
        return count;
    }

    function setCount(uint256 newValue) external onlyOwner returns (uint256) {
        require(newValue != count, "Counter: value unchanged");
        count = newValue;
        emit CountChanged(msg.sender, count);
        return count;
    }

    function setPaused(bool value) external onlyOwner {
        paused = value;
        emit PausedChanged(value);
    }

    function transferOwnership(address newOwner) external onlyOwner {
        require(newOwner != address(0), "Counter: zero owner");
        emit OwnershipTransferred(owner, newOwner);
        owner = newOwner;
    }
}

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

/// @title EscrowVault
/// @notice Three-party escrow (buyer, seller, arbiter) with an explicit state machine.
/// @dev Single file, no imports. Exercises access control, value transfer and state guards.
contract EscrowVault {
    enum State {
        AWAITING_PAYMENT,
        AWAITING_DELIVERY,
        COMPLETE,
        REFUNDED
    }

    address public immutable buyer;
    address public immutable seller;
    address public immutable arbiter;

    State public state;
    uint256 public amount;

    event Deposited(address indexed buyer, uint256 amount);
    event Released(address indexed seller, uint256 amount);
    event Refunded(address indexed buyer, uint256 amount);

    constructor(address seller_, address arbiter_) {
        require(seller_ != address(0), "Escrow: zero seller");
        require(arbiter_ != address(0), "Escrow: zero arbiter");
        buyer = msg.sender;
        seller = seller_;
        arbiter = arbiter_;
        state = State.AWAITING_PAYMENT;
    }

    function deposit() external payable {
        require(msg.sender == buyer, "Escrow: only buyer");
        require(state == State.AWAITING_PAYMENT, "Escrow: wrong state");
        require(msg.value > 0, "Escrow: no value");
        amount = msg.value;
        state = State.AWAITING_DELIVERY;
        emit Deposited(msg.sender, msg.value);
    }

    function confirmDelivery() external {
        require(msg.sender == buyer, "Escrow: only buyer");
        require(state == State.AWAITING_DELIVERY, "Escrow: wrong state");
        state = State.COMPLETE;
        (bool ok, ) = payable(seller).call{value: amount}("");
        require(ok, "Escrow: release failed");
        emit Released(seller, amount);
    }

    function refund() external {
        require(msg.sender == arbiter, "Escrow: only arbiter");
        require(state == State.AWAITING_DELIVERY, "Escrow: wrong state");
        state = State.REFUNDED;
        uint256 value = amount;
        amount = 0;
        (bool ok, ) = payable(buyer).call{value: value}("");
        require(ok, "Escrow: refund failed");
        emit Refunded(buyer, value);
    }
}

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

/// @title SimpleAuction
/// @notice Time-bounded auction with refund tracking, modelled after the Solidity docs example.
/// @dev Single file, no imports. Time is read from block.timestamp so tests must time-travel.
contract SimpleAuction {
    address payable public beneficiary;
    uint256 public auctionEnd;
    address public highestBidder;
    uint256 public highestBid;
    bool public ended;

    mapping(address => uint256) public pendingReturns;

    event HighestBidIncreased(address indexed bidder, uint256 amount);
    event AuctionEnded(address indexed winner, uint256 amount);
    event Withdrawal(address indexed bidder, uint256 amount);

    constructor(address payable beneficiary_, uint256 duration) {
        require(beneficiary_ != address(0), "Auction: zero beneficiary");
        require(duration > 0, "Auction: zero duration");
        beneficiary = beneficiary_;
        auctionEnd = block.timestamp + duration;
    }

    function bid() external payable {
        require(!ended, "Auction: already ended");
        require(block.timestamp < auctionEnd, "Auction: auction ended");
        require(msg.value > highestBid, "Auction: bid too low");

        if (highestBid != 0) {
            pendingReturns[highestBidder] += highestBid;
        }
        highestBidder = msg.sender;
        highestBid = msg.value;
        emit HighestBidIncreased(msg.sender, msg.value);
    }

    function withdraw() external returns (uint256) {
        uint256 amount = pendingReturns[msg.sender];
        require(amount > 0, "Auction: nothing to withdraw");
        pendingReturns[msg.sender] = 0;
        (bool ok, ) = payable(msg.sender).call{value: amount}("");
        require(ok, "Auction: withdrawal failed");
        emit Withdrawal(msg.sender, amount);
        return amount;
    }

    function endAuction() external {
        require(block.timestamp >= auctionEnd, "Auction: not ended yet");
        require(!ended, "Auction: already finalized");
        ended = true;
        emit AuctionEnded(highestBidder, highestBid);
        if (highestBid > 0) {
            (bool ok, ) = beneficiary.call{value: highestBid}("");
            require(ok, "Auction: beneficiary transfer failed");
        }
    }
}

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

/// @title SimpleERC20
/// @notice ERC20 subset with a fixed 1% transfer fee credited to a fee recipient.
/// @dev Single file, no imports. Deliberately keeps public state-variable getters,
///      events, mappings and constants so the layout pass has something to protect.
contract SimpleERC20 {
    string public name;
    string public symbol;
    uint8 public constant decimals = 18;
    uint256 public totalSupply;

    uint256 public constant BPS_DENOMINATOR = 10_000;
    uint256 public constant TRANSFER_FEE_BPS = 100;

    address public feeRecipient;

    mapping(address => uint256) public balanceOf;
    mapping(address => mapping(address => uint256)) public allowance;

    event Transfer(address indexed from, address indexed to, uint256 value);
    event Approval(address indexed owner, address indexed spender, uint256 value);
    event FeeCharged(address indexed payer, address indexed recipient, uint256 amount);

    constructor(string memory name_, string memory symbol_, uint256 initialSupply, address feeRecipient_) {
        require(feeRecipient_ != address(0), "ERC20: zero fee recipient");
        name = name_;
        symbol = symbol_;
        totalSupply = initialSupply;
        feeRecipient = feeRecipient_;
        balanceOf[msg.sender] = initialSupply;
        emit Transfer(address(0), msg.sender, initialSupply);
    }

    function transfer(address to, uint256 amount) external returns (bool) {
        _transfer(msg.sender, to, amount);
        return true;
    }

    function approve(address spender, uint256 amount) external returns (bool) {
        require(spender != address(0), "ERC20: approve to zero address");
        allowance[msg.sender][spender] = amount;
        emit Approval(msg.sender, spender, amount);
        return true;
    }

    function transferFrom(address from, address to, uint256 amount) external returns (bool) {
        uint256 allowed = allowance[from][msg.sender];
        require(allowed >= amount, "ERC20: insufficient allowance");
        if (allowed != type(uint256).max) {
            allowance[from][msg.sender] = allowed - amount;
        }
        _transfer(from, to, amount);
        return true;
    }

    function _transfer(address from, address to, uint256 amount) internal {
        require(to != address(0), "ERC20: transfer to zero address");
        require(balanceOf[from] >= amount, "ERC20: insufficient balance");

        uint256 fee = (amount * TRANSFER_FEE_BPS) / BPS_DENOMINATOR;
        uint256 net = amount - fee;

        balanceOf[from] -= amount;
        balanceOf[to] += net;
        emit Transfer(from, to, net);

        if (fee > 0) {
            balanceOf[feeRecipient] += fee;
            emit Transfer(from, feeRecipient, fee);
            emit FeeCharged(from, feeRecipient, fee);
        }
    }
}

"""Four-dimension evaluation for the multi-level obfuscator (Phase 5).

Produces ``eval/output/metrics_summary.csv`` with one row per
``contract x level x solc-optimizer setting`` (4 x 4 x 2 = 32 rows) covering:

* **Potency** - ``ast_nodes`` (AST node count) and ``cfg_basic_blocks`` / ``cfg_edges``
  from Slither, which is always given the explicit solc 0.8.20 binary path.
* **Stealth** - ``opcode_cosine_sim``: cosine similarity between the runtime opcode
  frequency vector of a variant and its own L0 baseline (closer to 1.0 is stealthier).
* **Resilience** - ``bytecode_diff_sim`` (difflib ratio of runtime hex, lower is better)
  and ``optimizer_retention_rate``: how much of the added control-flow complexity
  survives ``solc --optimize``.  Slither's CFG is derived from the Solidity AST and is
  identical for both optimizer settings, so retention is measured on runtime-bytecode
  basic blocks, counted as ``JUMPDEST`` tokens in solc's disassembled opcode list (push
  payloads are separate tokens, so a ``5b`` byte inside push data can never be
  miscounted); that is exactly where the optimizer can delete injected code.
* **Cost** - ``bytecode_size_kb``, ``deploy_gas``, ``avg_exec_gas`` and their growth
  percentages relative to the L0 baseline of the same optimizer setting.

The script also exports the L0 and L3 runtime bytecode of ``SimpleERC20`` as plain hex
text files for the Dedaub decompilation comparison.

Run from the repository root::

    python eval/run_eval.py
"""

def count_ast_nodes(ast: dict) -> int:
    """Iterative AST node count (every dict carrying a nodeType)."""
    total = 0
    stack: list[dict] = [ast]
    while stack:
        node = stack.pop()
        total += 1
        for value in node.values():
            if isinstance(value, dict) and "nodeType" in value:
                stack.append(value)
            elif isinstance(value, list):
                stack.extend(item for item in value if isinstance(item, dict) and "nodeType" in item)
    return total


def slither_cfg(path: Path) -> tuple[int, int]:
    """(basic blocks, edges) summed over every non-constructor function via Slither."""
    from slither.slither import Slither

    analysis = Slither(str(path), solc=str(get_solc_executable()))
    blocks = 0
    edges = 0
    for contract in analysis.contracts:
        for function in contract.functions:
            if function.is_constructor:
                continue
            blocks += len(function.nodes)
            edges += sum(len(node.sons) for node in function.nodes)
    return blocks, edges


def opcode_histogram(opcodes: str) -> Counter[str]:
    return Counter(opcodes.split())


def cosine_similarity(left: Counter[str], right: Counter[str]) -> float:
    shared = set(left) | set(right)
    dot = sum(left[key] * right[key] for key in shared)
    norm_left = math.sqrt(sum(value * value for value in left.values()))
    norm_right = math.sqrt(sum(value * value for value in right.values()))
    if norm_left == 0 or norm_right == 0:
        return 0.0
    return dot / (norm_left * norm_right)


def runtime_basic_blocks(opcodes: str) -> int:
    """Basic-block proxy on deployed code: one JUMPDEST per entry point plus the entry."""
    return opcodes.split().count("JUMPDEST") + 1


def gas_scenario(name: str, accounts: list[str]) -> tuple[tuple[Any, ...], list[tuple[str, tuple, int, int]]]:
    """Deployment arguments and the core call sequence used for gas measurement."""

def measure_gas(compilation: CompilationResult, name: str) -> tuple[int, float]:
    """Deploy on a fresh py-evm chain and average the core-call gas."""
    w3 = Web3(EthereumTesterProvider())
    accounts = list(w3.eth.accounts)
    deploy_args, calls = gas_scenario(name, accounts)

    factory = w3.eth.contract(abi=compilation.abi, bytecode=compilation.bytecode)
    deploy_receipt = w3.eth.wait_for_transaction_receipt(
        factory.constructor(*deploy_args).transact({"from": accounts[0]})
    )
    if deploy_receipt.status != 1:
        raise RuntimeError(f"deployment failed for {name}")

    contract = w3.eth.contract(address=deploy_receipt.contractAddress, abi=compilation.abi)
    gas_used: list[int] = []
    for function_name, args, value, sender_index in calls:
        receipt = w3.eth.wait_for_transaction_receipt(
            getattr(contract.functions, function_name)(*args).transact(
                {"from": accounts[sender_index], "value": value}
            )
        )
        if receipt.status != 1:
            raise RuntimeError(f"{name}.{function_name} failed during gas measurement")
        gas_used.append(receipt.gasUsed)

    return deploy_receipt.gasUsed, mean(gas_used)

        for name in CONTRACTS:
            path = directory / f"{name}.sol"
            if not path.is_file():
                raise FileNotFoundError(f"missing contract source: {path}")
            if path not in cfg_cache:

            for label, optimize in OPTIMIZER_SETTINGS:
                text, _ = read_source(path)
                compilation = compile_source(text, optimize=optimize, source_name=path.name)
                compiled[(name, level, label)] = compilation
                deploy_gas, avg_exec_gas = measure_gas(compilation, name)

                rows.append(
                    {
                        "contract": name,
                        "level": level,
                        "optimize": label,
                        "ast_nodes": count_ast_nodes(compilation.ast),
                        "cfg_basic_blocks": cfg_cache[path][0],
                        "cfg_edges": cfg_cache[path][1],
                        "runtime_basic_blocks": runtime_basic_blocks(compilation.opcodes),
                        "opcode_cosine_sim": None,
                        "bytecode_diff_sim": None,
                        "optimizer_retention_rate": None,
                        "bytecode_size_kb": compilation.deployed_bytecode_size / 1024.0,
                        "deploy_gas": deploy_gas,
                        "avg_exec_gas": avg_exec_gas,
                        "deploy_gas_delta_pct": None,
                        "avg_exec_gas_delta_pct": None,
                    }
                )
    return rows, compiled


def derive_metrics(
    rows: list[dict[str, Any]],
    compiled: dict[tuple[str, str, str], CompilationResult],
) -> None:
    """Fill similarity, growth and retention columns once the L0 baseline is known."""
    index = {(row["contract"], row["level"], row["optimize"]): row for row in rows}

    for row in rows:
        key = (row["contract"], row["level"], row["optimize"])
        baseline_key = (row["contract"], "L0", row["optimize"])
        current = compiled[key]
        baseline = compiled[baseline_key]
        baseline_row = index[baseline_key]

        row["opcode_cosine_sim"] = cosine_similarity(
            opcode_histogram(baseline.opcodes), opcode_histogram(current.opcodes)
        )
        row["bytecode_diff_sim"] = SequenceMatcher(
            None, baseline.deployed_bytecode, current.deployed_bytecode
        ).ratio()
        row["deploy_gas_delta_pct"] = (
            (row["deploy_gas"] - baseline_row["deploy_gas"]) / baseline_row["deploy_gas"] * 100.0
        )
        row["avg_exec_gas_delta_pct"] = (
            (row["avg_exec_gas"] - baseline_row["avg_exec_gas"])
            / baseline_row["avg_exec_gas"]
            * 100.0
        )

    for row in rows:
        row["optimizer_retention_rate"] = _retention(index, row["contract"], row["level"])


def _retention(
    index: dict[tuple[str, str, str], dict[str, Any]],
    contract: str,
    level: str,
) -> float | None:
    if level == "L0":
        return None
    base_off = index[(contract, "L0", "off")]["runtime_basic_blocks"]
    base_on = index[(contract, "L0", "on")]["runtime_basic_blocks"]
    added_off = index[(contract, level, "off")]["runtime_basic_blocks"] - base_off
    added_on = index[(contract, level, "on")]["runtime_basic_blocks"] - base_on
    if added_off <= 0:
        return None
    return added_on / added_off


def _format(value: Any) -> Any:
    if value is None:
        return ""
    if isinstance(value, float):
        return f"{value:.6f}"
    return value

    with CSV_PATH.open("w", encoding="utf-8", newline="") as handle:
        writer = csv.DictWriter(handle, fieldnames=FIELDS, lineterminator="\n")
        writer.writeheader()
        for row in rows:
            writer.writerow({key: _format(row[key]) for key in FIELDS})

"""Command line interface for the Solidity multi-level obfuscator.

Usage::

    python -m obf.cli -i contracts -o eval/output/obfuscated -l 3 --seed 42 --max-injections 2
    python -m obf.cli -i contracts -o eval/output/obfuscated --all-levels --seed 42

Directory input writes ``<output>/L<level>/<Name>.sol``; ``--all-levels`` writes the
L1, L2 and L3 trees in one run.  Every file is written as UTF-8 with LF newlines, and
the console summary is plain ASCII so Windows PowerShell and Linux terminals agree.

import argparse
import sys
from dataclasses import dataclass
from pathlib import Path
from typing import Sequence

from obf.compiler import CompilationError, read_source
from obf.engine import PipelineError, run_pipeline

PROG = "python -m obf.cli"
ALL_LEVELS = (1, 2, 3)


@dataclass(frozen=True)
class Job:
    """One contract to obfuscate at one level."""

    source: Path
    level: int
    destination: Path


@dataclass
class Outcome:
    contract: str
    level: int
    patches: int | str
    size: int | str
    status: str
    message: str = ""


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog=PROG,
        description="Obfuscate Solidity sources at level 1 (layout), 2 (data) or 3 (control flow).",
        epilog="Output is written as UTF-8 with LF newlines; the same --seed reproduces identical bytes.",
    )
    parser.add_argument("-i", "--input", required=True, metavar="PATH", help="a .sol file or a directory of .sol files")
    parser.add_argument("-o", "--output", required=True, metavar="PATH", help="output directory, or a .sol path for single-file mode")
    parser.add_argument("-l", "--level", type=int, choices=(0, 1, 2, 3), default=None, help="obfuscation level to produce (0 copies the source)")
    parser.add_argument("--all-levels", action="store_true", help="produce levels 1, 2 and 3 in one run")
    parser.add_argument("--seed", type=int, default=42, help="deterministic RNG seed (default: 42)")
    parser.add_argument("--max-injections", type=int, default=3, dest="max_injections", help="maximum control-flow injections per function (default: 3)")
    return parser


def collect_jobs(input_path: Path, output_path: Path, levels: Sequence[int]) -> list[Job]:
    """Resolve the input/output pair into concrete write jobs."""
    if input_path.is_dir():
        sources = sorted(path for path in input_path.glob("*.sol") if path.is_file())
        if not sources:
            raise ValueError(f"no .sol files found in {input_path}")
        return [Job(source, level, output_path / f"L{level}" / source.name) for level in levels for source in sources]

    if input_path.is_file():
        if len(levels) > 1:
            base = output_path
            return [Job(input_path, level, base / f"L{level}" / input_path.name) for level in levels]
        if output_path.suffix.lower() == ".sol":
            return [Job(input_path, levels[0], output_path)]
        return [Job(input_path, levels[0], output_path / f"L{levels[0]}" / input_path.name)]

    raise ValueError(f"input not found: {input_path}")


def _print_table(rows: list[Outcome]) -> None:
    headers = ("Contract", "Level", "Patches", "Bytes", "Status")
    cells = [(row.contract, str(row.level), str(row.patches), str(row.size), row.status) for row in rows]
    widths = [max(len(headers[i]), *(len(row[i]) for row in cells)) for i in range(len(headers))]

    separator = "+" + "+".join("-" * (width + 2) for width in widths) + "+"

    def line(values: Sequence[str]) -> str:
        return "|" + "|".join(f" {value:<{width}} " for value, width in zip(values, widths)) + "|"

    print(separator)
    print(line(headers))
    print(separator)
    for row in cells:
        print(line(row))
    print(separator)


def run_job(job: Job, seed: int, max_injections: int) -> Outcome:
    try:
        source_text, _ = read_source(job.source)
        result = run_pipeline(
            source_text,
            level=job.level,
            seed=seed,
            max_injections=max_injections,
            source_name=job.source.name,
        )
        job.destination.parent.mkdir(parents=True, exist_ok=True)
        job.destination.write_bytes(result.source_bytes)
    except (CompilationError, PipelineError, OSError, ValueError) as exc:
        message = " ".join(str(exc).split())
        print(f"ERROR {job.source.name} (level {job.level}): {message}", file=sys.stderr)
        return Outcome(job.source.stem, job.level, "-", "-", "FAILED")

    return Outcome(job.source.stem, job.level, result.total_applied, len(result.source_bytes), "OK")


def main(argv: Sequence[str] | None = None) -> int:
    parser = build_parser()
    args = parser.parse_args(argv)

    if args.all_levels and args.level is not None:
        parser.error("use either --level or --all-levels, not both")
    if not args.all_levels and args.level is None:
        parser.error("pass --level N or --all-levels")
    if args.max_injections < 0:
        parser.error("--max-injections must be >= 0")

    levels = ALL_LEVELS if args.all_levels else (args.level,)

    try:
        jobs = collect_jobs(Path(args.input), Path(args.output), levels)
    except ValueError as exc:
        print(f"ERROR: {exc}", file=sys.stderr)
        return 2

    print(
        f"SolObfuscator: {len(jobs)} file(s), levels {','.join(str(level) for level in levels)}, "
        f"seed {args.seed}, max_injections {args.max_injections}"
    )

    outcomes = [run_job(job, args.seed, args.max_injections) for job in jobs]
    _print_table(outcomes)

    failed = [outcome for outcome in outcomes if outcome.status != "OK"]
    total_patches = sum(outcome.patches for outcome in outcomes if isinstance(outcome.patches, int))
    print(
        f"Summary: {len(outcomes) - len(failed)}/{len(outcomes)} file(s) written, "
        f"{total_patches} patch(es) applied, output {Path(args.output)}"
    )
    if failed:
        print(f"Result: FAILED ({len(failed)} file(s))", file=sys.stderr)
        return 1

    print("Result: OK")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

=== FILE: obf/compiler.py ===
"""Compilation layer built on :mod:`py_solc_x` (solc 0.8.20).

Two invariants from the engineering spec drive this module:

* **LF normalisation** - every source string is rewritten to ``\\n`` before it is
  compiled or patched.  solc reports AST offsets as UTF-8 *byte* offsets, so a
  CRLF source would shift every single offset handed to the patch engine.
* **Explicit solc path** - the compiler binary is resolved through py-solc-x and
  returned by :func:`get_solc_executable`, never through ``PATH``.  The same path
  is passed to Slither later so both tools agree on 0.8.20.

The compiled artifact is exposed as :class:`CompilationResult`, which carries the
ABI, creation/runtime bytecode, the runtime opcode listing and the full AST that
later passes address by byte range.
"""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import solcx
from solcx import compile_standard
from solcx.install import get_executable

SOLC_VERSION = "0.8.20"
DEFAULT_OPTIMIZER_RUNS = 200

#: Outputs requested from solc for every compilation.
OUTPUT_SELECTION = {
    "*": {
        "": ["ast"],
        "*": [
            "abi",
            "evm.bytecode.object",
            "evm.deployedBytecode.object",
            "evm.deployedBytecode.opcodes",
        ],
    },
}


class CompilationError(RuntimeError):
    """Raised when solc rejects a source file."""


@dataclass(frozen=True)
class CompilationResult:
    """Everything downstream phases need from a single solc invocation."""

    source_name: str
    contract_name: str
    abi: list[dict]
    bytecode: str
    deployed_bytecode: str
    opcodes: str
    ast: dict
    solc_version: str = SOLC_VERSION

    @property
    def bytecode_bytes(self) -> bytes:
        """Creation bytecode as raw bytes (empty string means nothing to deploy)."""
        return bytes.fromhex(self.bytecode)

    @property
    def deployed_bytecode_bytes(self) -> bytes:
        """Runtime bytecode as raw bytes."""
        return bytes.fromhex(self.deployed_bytecode)

    @property
    def deployed_bytecode_size(self) -> int:
        """Runtime size in bytes (EIP-170 limit check uses this)."""
        return len(self.deployed_bytecode) // 2

    @property
    def opcode_list(self) -> list[str]:
        return self.opcodes.split()


def normalize_source(source_str: str) -> tuple[str, bytes]:
    """Return ``(lf_text, utf8_bytes)`` for one source file.

    The two values are derived from the same string, so byte offsets reported by
    solc for ``lf_text`` are valid indices into ``utf8_bytes``.  Any ``\\r\\n`` or
    lone ``\\r`` becomes ``\\n``; UTF-8 multi-byte characters are preserved.
    """
    if not isinstance(source_str, str):
        raise TypeError(f"source_str must be str, got {type(source_str).__name__}")

    text = source_str.replace("\r\n", "\n").replace("\r", "\n")
    return text, text.encode("utf-8")


def read_source(path: str | Path) -> tuple[str, bytes]:
    """Read a ``.sol`` file as UTF-8, return its LF-normalised text and bytes."""
    raw = Path(path).read_bytes()
    return normalize_source(raw.decode("utf-8"))


def get_solc_executable(version: str = SOLC_VERSION) -> str:
    """Return the absolute path of the pinned solc binary, installing it if needed.

    Slither must be given ``solc=...`` explicitly; using this helper keeps the
    analyser on the same compiler build as the obfuscator.
    """
    installed = {str(item) for item in solcx.get_installed_solc_versions()}
    if version not in installed:
        solcx.install_solc(version)
    return str(get_executable(version))


def compile_source(
    source_str: str,
    optimize: bool = False,
    source_name: str = "Main.sol",
    contract_name: str | None = None,
) -> CompilationResult:
    """Compile one Solidity source string with solc 0.8.20.

    Args:
        source_str: Solidity source; CRLF input is normalised to LF first.
        optimize: enable solc's optimizer (200 runs) when true.
        source_name: logical file name used inside standard-JSON output.
        contract_name: contract to extract; defaults to the only contract found.

    Raises:
        CompilationError: solc reported a syntax or type error.
    """
    lf_source, _ = normalize_source(source_str)

    standard_input = {
        "language": "Solidity",
        "sources": {source_name: {"content": lf_source}},
        "settings": {
            "optimizer": {"enabled": bool(optimize), "runs": DEFAULT_OPTIMIZER_RUNS},
            "outputSelection": OUTPUT_SELECTION,
        },
    }

    try:
        output = compile_standard(standard_input, solc_version=SOLC_VERSION)
    except solcx.exceptions.SolcError as exc:
        raise CompilationError(
            f"solc {SOLC_VERSION} failed to compile {source_name} (optimize={optimize}):\n{exc}"
        ) from exc

    ast = output.get("sources", {}).get(source_name, {}).get("ast")
    if ast is None:
        raise CompilationError(f"solc produced no AST for {source_name}")

    contracts = output.get("contracts", {}).get(source_name, {})
    if not contracts:
        raise CompilationError(f"solc produced no contract for {source_name}")

    if contract_name is None:
        if len(contracts) != 1:
            raise CompilationError(
                f"{source_name} defines several contracts ({sorted(contracts)}); pass contract_name"
            )
        contract_name = next(iter(contracts))
    if contract_name not in contracts:
        raise CompilationError(f"{source_name} does not define contract {contract_name!r}")

    compiled = contracts[contract_name]
    evm = compiled["evm"]
    return CompilationResult(
        source_name=source_name,
        contract_name=contract_name,
        abi=compiled["abi"],
        bytecode=evm["bytecode"]["object"],
        deployed_bytecode=evm["deployedBytecode"]["object"],
        opcodes=evm["deployedBytecode"]["opcodes"],
        ast=ast,
    )

=== FILE: obf/engine.py ===
"""Byte-precise patch engine for the Solidity obfuscator.

The engine never rewrites the AST back into source code.  Instead every obfuscation
pass reports *byte ranges* into the LF-normalised UTF-8 source, and the engine applies
those ranges in one descending sweep so earlier offsets stay valid.  After each pass
the patched source is recompiled, which both proves the pass kept the contract valid
and refreshes the AST byte coordinates for the next pass.

Contract of this module:

* :func:`normalize_source` / :func:`read_source` (re-exported from ``obf.compiler``)
  are the only supported ways to obtain the bytes that offsets refer to.
* :func:`parse_src` turns solc's ``"start:length:file_id"`` into an absolute range.
* :func:`walk_ast` walks the solc AST and hands every node its ancestor chain.
* :func:`apply_patches` validates ranges, rejects overlaps and applies patches from
  the end of the file backwards.
* :func:`run_pipeline` chains passes per level with per-pass recompilation.
"""

from __future__ import annotations

import importlib
import logging
import random
from dataclasses import dataclass
from typing import Any, Callable, Iterable, Sequence

from obf.compiler import (
    CompilationError,
    CompilationResult,
    compile_source,
    normalize_source,
    read_source,
)

logger = logging.getLogger(__name__)

__all__ = [
    "LEVEL_PASSES",
    "PassSpec",
    "PassStat",
    "Patch",
    "PatchConflictError",
    "PatchError",
    "PatchRangeError",
    "PipelineCompileError",
    "PipelineError",
    "PipelineResult",
    "apply_patches",
    "normalize_source",
    "parse_src",
    "read_source",
    "resolve_passes",
    "run_pipeline",
    "walk_ast",
]

#: ``(start_byte, end_byte, replacement_bytes)`` in normalised UTF-8 byte space.
Patch = tuple[int, int, bytes]

#: A pass reports patches for the *current* source and AST.
PassFunc = Callable[..., list[Patch]]

#: Which passes each obfuscation level enables.  0 is the unmodified baseline.
LEVEL_PASSES: dict[int, tuple[str, ...]] = {
    0: (),
    1: ("layout",),
    2: ("layout", "data"),
    3: ("layout", "data", "control"),
}


class PatchError(ValueError):
    """Base class for invalid or conflicting patch ranges."""


class PatchRangeError(PatchError):
    """A patch points outside the source or has an invalid range."""


class PatchConflictError(PatchError):
    """Two patches overlap, or two zero-length inserts share one position."""


class PipelineError(RuntimeError):
    """A pass produced unusable output or the pipeline configuration is invalid."""


class PipelineCompileError(PipelineError):
    """The source produced by a pass no longer compiles."""

    def __init__(self, pass_name: str, source_name: str, error: Exception) -> None:
        self.pass_name = pass_name
        self.source_name = source_name
        self.error = error
        super().__init__(
            f"pass {pass_name!r} broke compilation of {source_name}: {error}"
        )


@dataclass(frozen=True)
class PassSpec:
    """A named pass: ``get_patches(source_bytes, ast, rng, **kwargs)``."""

    name: str
    get_patches: PassFunc


@dataclass(frozen=True)
class PassStat:
    """What one pass changed, for the structured pipeline log."""

    name: str
    requested: int
    applied: int
    skipped: int
    size_before: int
    size_after: int


@dataclass(frozen=True)
class PipelineResult:
    """Final source plus per-pass statistics for one pipeline run."""

    level: int
    seed: int
    source: str
    source_bytes: bytes
    stats: tuple[PassStat, ...]
    compilation: CompilationResult

    @property
    def total_applied(self) -> int:
        return sum(stat.applied for stat in self.stats)

    @property
    def size(self) -> int:
        return len(self.source_bytes)


def parse_src(src: str) -> tuple[int, int]:
    """Convert solc's ``"start:length:file_id"`` into ``(start, end)`` byte offsets."""
    if not isinstance(src, str):
        raise TypeError(f"src must be str, got {type(src).__name__}")

    parts = src.split(":")
    if len(parts) != 3:
        raise ValueError(f"malformed solc src {src!r}: expected 'start:length:file_id'")

    try:
        start, length, file_id = (int(part) for part in parts)
    except ValueError:
        raise ValueError(f"malformed solc src {src!r}: non-integer component") from None

    if start < 0 or length < 0 or file_id < 0:
        raise ValueError(f"malformed solc src {src!r}: negative component")
    return start, start + length


def walk_ast(
    node: Any,
    callback: Callable[[dict[str, Any], tuple[dict[str, Any], ...]], None],
    ancestors: tuple[dict[str, Any], ...] = (),
) -> int:
    """Recursively visit every AST node, passing the chain of enclosing nodes.

    ``callback(node, ancestors)`` is called depth-first in source order; ``ancestors``
    is root-first and *excludes* ``node`` itself.  Only dictionaries carrying a
    ``nodeType`` are treated as nodes, so ``src``/``nameLocation`` strings and other
    metadata are never visited.  Returns the number of visited nodes.
    """
    if not isinstance(node, dict) or "nodeType" not in node:
        return 0

    callback(node, ancestors)
    visited = 1
    child_ancestors = ancestors + (node,)

    for value in node.values():
        if isinstance(value, dict) and "nodeType" in value:
            visited += walk_ast(value, callback, child_ancestors)
        elif isinstance(value, list):
            for item in value:
                if isinstance(item, dict) and "nodeType" in item:
                    visited += walk_ast(item, callback, child_ancestors)
    return visited


def _validate_patch(patch: Patch, size: int) -> None:
    if not (isinstance(patch, tuple) and len(patch) == 3):
        raise PatchRangeError(f"patch must be (start, end, bytes), got {patch!r}")
    start, end, replacement = patch
    if not isinstance(start, int) or not isinstance(end, int):
        raise PatchRangeError(f"patch offsets must be int, got {patch!r}")
    if not isinstance(replacement, bytes):
        raise PatchRangeError(f"patch replacement must be bytes, got {type(replacement).__name__}")
    if start < 0 or end < start:
        raise PatchRangeError(f"invalid patch range ({start}, {end})")
    if end > size:
        raise PatchRangeError(f"patch range ({start}, {end}) exceeds source size {size}")


def _apply_patches(
    source_bytes: bytes,
    patches: Iterable[Patch],
    on_conflict: str,
) -> tuple[bytes, int, int]:
    """Apply patches and return ``(result, applied, skipped)``."""
    if not isinstance(source_bytes, (bytes, bytearray)):
        raise TypeError(f"source_bytes must be bytes, got {type(source_bytes).__name__}")
    source = bytes(source_bytes)

    prepared: list[Patch] = []
    for patch in patches:
        _validate_patch(patch, len(source))
        prepared.append(patch)

    # Stable sort by start; equal starts keep their input order so that the
    # descending sweep is deterministic.
    prepared.sort(key=lambda item: (item[0], item[1]))

    accepted: list[Patch] = []
    skipped = 0
    for patch in prepared:
        if not accepted:
            accepted.append(patch)
            continue

        previous = accepted[-1]
        prev_start, prev_end = previous[0], previous[1]
        start, end = patch[0], patch[1]
        overlaps = start < prev_end or (start == prev_start and (start == end or prev_start == prev_end))
        if not overlaps:
            accepted.append(patch)
            continue

        if on_conflict == "skip":
            logger.warning("skipping conflicting patch %r (conflicts with %r)", patch, previous)
            skipped += 1
            continue
        if on_conflict != "error":
            raise ValueError(f"on_conflict must be 'error' or 'skip', got {on_conflict!r}")
        raise PatchConflictError(f"patch {patch!r} overlaps patch {previous!r}")

    result = bytearray(source)
    for start, end, replacement in sorted(accepted, key=lambda item: (item[0], item[1]), reverse=True):
        result[start:end] = replacement
    return bytes(result), len(accepted), skipped


def apply_patches(
    source_bytes: bytes,
    patches: Iterable[Patch],
    on_conflict: str = "error",
) -> bytes:
    """Apply byte patches to ``source_bytes`` and return the new bytes.

    Patches are applied from the highest offset downwards, so a patch never shifts the
    coordinates of the patches that follow it.  Ranges are validated against the
    source size, and overlaps are rejected before anything is applied.

    Args:
        source_bytes: LF-normalised UTF-8 source bytes.
        patches: iterable of ``(start, end, replacement_bytes)``.
        on_conflict: ``"error"`` (default) raises :class:`PatchConflictError`;
            ``"skip"`` drops the conflicting patch, logs a warning and keeps going.

    Raises:
        PatchRangeError: a patch is malformed or outside the source.
        PatchConflictError: two patches overlap and ``on_conflict="error"``.
    """
    result, _, _ = _apply_patches(source_bytes, patches, on_conflict)
    return result


def resolve_passes(level: int) -> list[PassSpec]:
    """Load the pass modules for ``level`` in pipeline order.

    Phase 3 adds ``obf.passes.layout`` / ``data`` / ``control``; until then levels
    above 0 fail with a clear error instead of silently doing nothing.
    """
    if level not in LEVEL_PASSES:
        raise ValueError(f"unknown obfuscation level {level}; expected 0..{max(LEVEL_PASSES)}")

    specs: list[PassSpec] = []
    for name in LEVEL_PASSES[level]:
        try:
            module = importlib.import_module(f"obf.passes.{name}")
        except ImportError as exc:
            raise PipelineError(
                f"level {level} needs pass {name!r} but obf.passes.{name} is not implemented yet"
            ) from exc
        get_patches = getattr(module, "get_patches", None)
        if not callable(get_patches):
            raise PipelineError(f"obf.passes.{name} must expose get_patches(source_bytes, ast, rng, **kwargs)")
        specs.append(PassSpec(name=name, get_patches=get_patches))
    return specs


def run_pipeline(
    source_str: str,
    level: int = 0,
    seed: int = 0,
    max_injections: int = 3,
    passes: Sequence[PassSpec] | None = None,
    source_name: str = "Main.sol",
    optimize: bool = False,
    on_conflict: str = "error",
) -> PipelineResult:
    """Run all passes for ``level`` with per-pass recompilation.

    The source is LF-normalised once; every pass receives the same byte space that
    solc reports offsets in.  After each pass the patched text is recompiled:

    * a compile failure raises :class:`PipelineCompileError` naming the pass, so a
      broken obfuscation step is blamed on the right module instead of a later one;
    * the refreshed AST becomes the coordinate system for the next pass, which
      removes all offset drift.

    ``passes`` overrides the level registry (used by the engine smoke tests); the
    random generator is seeded once per run, so an identical ``seed`` reproduces an
    identical output byte for byte.
    """
    lf_text, source_bytes = normalize_source(source_str)
    rng = random.Random(seed)
    compilation = compile_source(lf_text, optimize=optimize, source_name=source_name)

    specs = list(passes) if passes is not None else resolve_passes(level)
    stats: list[PassStat] = []

    for spec in specs:
        requested = list(
            spec.get_patches(source_bytes, compilation.ast, rng, max_injections=max_injections)
        )
        try:
            patched, applied, skipped = _apply_patches(source_bytes, requested, on_conflict)
        except PatchError as exc:
            raise PipelineError(f"pass {spec.name!r} produced invalid patches: {exc}") from exc

        try:
            patched_text = patched.decode("utf-8")
        except UnicodeDecodeError as exc:
            raise PipelineError(f"pass {spec.name!r} produced invalid UTF-8: {exc}") from exc

        try:
            compilation = compile_source(patched_text, optimize=optimize, source_name=source_name)
        except CompilationError as exc:
            raise PipelineCompileError(spec.name, source_name, exc) from exc

        stat = PassStat(
            name=spec.name,
            requested=len(requested),
            applied=applied,
            skipped=skipped,
            size_before=len(source_bytes),
            size_after=len(patched),
        )
        stats.append(stat)
        logger.info(
            "pass %s: %d patches applied, %d -> %d bytes",
            spec.name,
            applied,
            stat.size_before,
            stat.size_after,
        )
        source_bytes = patched

    return PipelineResult(
        level=level,
        seed=seed,
        source=source_bytes.decode("utf-8"),
        source_bytes=source_bytes,
        stats=tuple(stats),
        compilation=compilation,
    )

=== FILE: obf/passes/control.py ===
"""Level 3 - control-flow obfuscation.

For every non-``pure`` function, up to ``max_injections`` statements are rewritten as

.. code-block:: solidity

    if (<always-false predicate>) { <side-effect-free local arithmetic> }
    if (<always-true predicate>) { <original statement> } else { <side-effect-free arithmetic> }

The predicates read runtime chain state (``block.timestamp``, ``block.number``,
``tx.gasprice``, ``msg.sender``), so solc cannot fold them away; ``always-false``
variants are provably false but not constant-foldable (e.g. ``x % 2 == 3``).

Red lines enforced here:

* ``VariableDeclarationStatement`` is never selected, so a local declared before the
  branch can never leak into a new block scope and trigger "Undeclared identifier".
* ``pure`` functions are skipped entirely: their bodies may not read chain state, and
  a runtime predicate would not compile there.
* at most ``max_injections`` rewrites per function (default 3), limiting stack growth
  and keeping the risk of "Stack too deep" at bay.

Injected dead code only declares and recomputes a local ``uint256``: it never writes
state, never calls ``revert``/``assert`` and never emits events.
"""

from __future__ import annotations

import random
from typing import Any

from obf.engine import Patch, parse_src, walk_ast

#: Always-true predicates that depend on runtime chain state.
TRUE_PREDICATES: tuple[bytes, ...] = (
    b"((block.timestamp & 1) <= 1)",
    b"((uint256(uint160(msg.sender)) % 2) < 2)",
    b"((tx.gasprice | 1) != 0)",
    b"((block.number | 1) != 0)",
    b"((block.timestamp | 1) != 0)",
)

#: Provably false predicates that solc still cannot constant-fold.
FALSE_PREDICATES: tuple[bytes, ...] = (
    b"((block.timestamp % 2) == 2)",
    b"((block.number & 1) == 2)",
    b"((tx.gasprice % 2) == 3)",
    b"((uint256(uint160(msg.sender)) % 2) == 2)",
    b"((block.number % 2) == 3)",
)

#: Statements that must never be wrapped (scope-sensitive declarations).
_SKIPPED_STATEMENTS = frozenset({"VariableDeclarationStatement"})


def _collect_names(ast: dict) -> set[str]:
    names: set[str] = set()

    def visit(node: dict, _ancestors: tuple[dict, ...]) -> None:
        name = node.get("name")
        if isinstance(name, str):
            names.add(name)

    walk_ast(ast, visit)
    return names


def _fresh_local(rng: random.Random, used: set[str]) -> str:
    while True:
        candidate = f"_0xd{rng.getrandbits(20):05x}"
        if candidate not in used:
            used.add(candidate)
            return candidate


def _dead_code(rng: random.Random, used: set[str]) -> bytes:
    """A local uint256 computation with no observable effect."""
    name = _fresh_local(rng, used)
    first = rng.randrange(1, 2**32)
    second = rng.randrange(1, 2**32)
    mask = rng.randrange(1, 2**32)
    return (
        f"uint256 {name} = (uint256({first}) ^ uint256({second})); "
        f"{name} = (({name} << 1) | uint256({mask}));"
    ).encode("ascii")


def _collect_immutables(ast: dict) -> set[int]:
    """Ids of ``immutable`` state variables.

    Solidity only allows an immutable to be assigned at construction time and *not*
    inside a conditional, so statements that mention one must never be wrapped.
    """
    ids: set[int] = set()

    def visit(node: dict, _ancestors: tuple[dict, ...]) -> None:
        if node.get("nodeType") == "VariableDeclaration" and node.get("mutability") == "immutable":
            ids.add(node["id"])

    walk_ast(ast, visit)
    return ids


def _mentions(node: dict, declaration_ids: set[int]) -> bool:
    found = False

    def visit(child: dict, _ancestors: tuple[dict, ...]) -> None:
        nonlocal found
        if child.get("nodeType") == "Identifier" and child.get("referencedDeclaration") in declaration_ids:
            found = True

    walk_ast(node, visit)
    return found


def _candidate_functions(ast: dict, immutable_ids: set[int]) -> list[tuple[dict, list[dict]]]:
    """Functions that may be injected, with their eligible top-level statements."""
    functions: list[tuple[dict, list[dict]]] = []

    def visit(node: dict, _ancestors: tuple[dict, ...]) -> None:
        if node.get("nodeType") != "FunctionDefinition":
            return
        if node.get("stateMutability") == "pure":
            return
        body = node.get("body")
        if not isinstance(body, dict) or body.get("nodeType") != "Block":
            return
        statements = [item for item in body.get("statements", []) if isinstance(item, dict)]
        candidates = [
            item
            for item in statements
            if item.get("nodeType") not in _SKIPPED_STATEMENTS
            and not _mentions(item, immutable_ids)
        ]
        if candidates:
            functions.append((node, candidates))

    walk_ast(ast, visit)
    return functions


def _inject(statement: bytes, rng: random.Random, used: set[str]) -> bytes:
    true_predicate = TRUE_PREDICATES[rng.randrange(len(TRUE_PREDICATES))]
    false_predicate = FALSE_PREDICATES[rng.randrange(len(FALSE_PREDICATES))]
    first_dead = _dead_code(rng, used)
    second_dead = _dead_code(rng, used)
    return (
        b"if ("
        + false_predicate
        + b") { "
        + first_dead
        + b" } if ("
        + true_predicate
        + b") { "
        + statement
        + b" } else { "
        + second_dead
        + b" }"
    )


def _statement_span(source: bytes, node: dict) -> tuple[int, int]:
    """Byte span of a statement, including its trailing semicolon.

    solc's ``src`` for an ``ExpressionStatement`` stops before the ``;``, so wrapping
    the raw range would drop the semicolon and produce a parser error.  Extend the
    span over optional whitespace when the next non-space byte is ``;``.
    """
    start, end = parse_src(node["src"])
    cursor = end
    while cursor < len(source) and source[cursor] in b" \t\r\n":
        cursor += 1
    if cursor < len(source) and source[cursor] == 0x3B:  # ';'
        return start, cursor + 1
    return start, end


def get_patches(
    source_bytes: bytes,
    ast: dict,
    rng: random.Random,
    max_injections: int = 3,
    **kwargs: Any,
) -> list[Patch]:
    """Level 3 entry point: wrap statements in opaque predicates and dead branches."""
    budget = int(max_injections)
    if budget <= 0:
        return []

    patches: list[Patch] = []
    used = _collect_names(ast)
    immutable_ids = _collect_immutables(ast)

    for _function, candidates in _candidate_functions(ast, immutable_ids):
        count = min(budget, len(candidates))
        if count <= 0:
            continue
        for index in sorted(rng.sample(range(len(candidates)), count)):
            statement = candidates[index]
            start, end = _statement_span(source_bytes, statement)
            replacement = _inject(source_bytes[start:end], rng, used)
            patches.append((start, end, replacement))

    return patches

=== FILE: obf/passes/data.py ===
"""Level 2 - data obfuscation.

* **Integer literals** are split with a random mask: ``N`` becomes
  ``(uint256(N ^ R) ^ uint256(R))``.  The conversion is only emitted where the
  surrounding expression is a ``uint256`` context, because Solidity 0.8 rejects
  implicit narrowing: a literal feeding a ``uint8``/``uint16``/``address`` or an array
  length is left alone.
* **Boolean literals** become constant-foldable comparisons of random byte pairs:
  ``true`` -> ``((0x1a ^ 0x2b) == 0x31)`` and ``false`` -> ``((0x1a ^ 0x2b) == 0x00)``.
  These are pure arithmetic, so they are also valid inside ``pure`` functions.

Every replacement is byte-precise: literals are addressed through their own ``src``
range, so no other token can be disturbed.
"""

from __future__ import annotations

import random
from typing import Any

from obf.engine import Patch, parse_src, walk_ast

#: Integer widths whose literals must not be rewritten with a uint256 expression.
_NARROW_INT_TYPES = frozenset(
    {
        "uint8",
        "uint16",
        "uint32",
        "uint64",
        "uint128",
        "int8",
        "int16",
        "int32",
        "int64",
        "int128",
    }
)

#: Contexts in which solc demands a compile-time constant integer.
_CONSTANT_CONTEXTS = frozenset({"PragmaDirective", "ArrayTypeName"})

_MAX_LITERAL = 2**64


def _type_string(node: dict) -> str:
    return (node.get("typeDescriptions") or {}).get("typeString", "")


def _base_type(node: dict) -> str:
    return _type_string(node).split(" ")[0]


def _is_uint256_context(node: dict, ancestors: tuple[dict, ...]) -> bool:
    """True when replacing ``node`` with a uint256 expression keeps the file valid."""
    for ancestor in reversed(ancestors):
        node_type = ancestor.get("nodeType")
        if node_type in _CONSTANT_CONTEXTS:
            return False

        base = _base_type(ancestor)
        if base in _NARROW_INT_TYPES:
            return False
        if base == "uint256":
            return True

        if node_type == "BinaryOperation":
            left = ancestor.get("leftExpression")
            right = ancestor.get("rightExpression")
            other = right if left is node else left
            if isinstance(other, dict) and _base_type(other) == "uint256":
                return True
        elif node_type == "Assignment":
            left = ancestor.get("leftHandSide")
            if isinstance(left, dict) and _base_type(left) == "uint256":
                return True

    return False


def obfuscate_numbers(source_bytes: bytes, ast: dict, rng: random.Random) -> list[Patch]:
    patches: list[Patch] = []

    def visit(node: dict, ancestors: tuple[dict, ...]) -> None:
        if node.get("nodeType") != "Literal" or node.get("kind") != "number":
            return
        if node.get("subdenomination"):
            return

        raw = node.get("value")
        if not isinstance(raw, str) or not raw.isdigit():
            return
        value = int(raw, 10)
        if value > _MAX_LITERAL:
            return
        if not _is_uint256_context(node, ancestors):
            return

        mask = rng.randrange(1, 100_001)
        expression = f"(uint256({value ^ mask}) ^ uint256({mask}))"
        start, end = parse_src(node["src"])
        patches.append((start, end, expression.encode("ascii")))

    walk_ast(ast, visit)
    return patches


def obfuscate_booleans(source_bytes: bytes, ast: dict, rng: random.Random) -> list[Patch]:
    patches: list[Patch] = []

    def visit(node: dict, _ancestors: tuple[dict, ...]) -> None:
        if node.get("nodeType") != "Literal" or node.get("kind") != "bool":
            return
        literal = node.get("value")
        if literal not in ("true", "false"):
            return

        left = rng.randrange(1, 255)
        right = rng.randrange(1, 255)
        while right == left:
            right = rng.randrange(1, 255)

        if literal == "true":
            expression = f"((0x{left:02x} ^ 0x{right:02x}) == 0x{left ^ right:02x})"
        else:
            expression = f"((0x{left:02x} ^ 0x{right:02x}) == 0x00)"

        start, end = parse_src(node["src"])
        patches.append((start, end, expression.encode("ascii")))

    walk_ast(ast, visit)
    return patches


def get_patches(
    source_bytes: bytes,
    ast: dict,
    rng: random.Random,
    **kwargs: Any,
) -> list[Patch]:
    """Level 2 entry point: obfuscate integer and boolean literals."""
    patches = obfuscate_numbers(source_bytes, ast, rng)
    patches.extend(obfuscate_booleans(source_bytes, ast, rng))
    return patches

"""Level 1 - layout obfuscation.

Two transformations, both emitted as byte patches so the engine can apply them in one
descending sweep:

1. **Comment and whitespace stripping** - a small byte scanner that understands string
   literals (including escapes), so ``//`` inside a string is never mistaken for a
   comment.  The SPDX licence line is preserved.  Runs of three or more newlines
   collapse to one blank line and indentation collapses to a single space.
2. **ABI-safe renaming** - only symbols that cannot appear in the external ABI:
   ``private``/``internal`` functions, local variables, and parameters of
   ``private``/``internal`` functions.  Declarations are addressed through solc's
   ``nameLocation`` (the identifier itself, never the whole statement), references
   through ``Identifier`` nodes whose ``referencedDeclaration`` points at the renamed
   node.  Public/external functions, state variables, events, modifiers, struct and
   enum members, constructors, ``receive``/``fallback`` and the parameters of
   public/external functions are never touched, so the ABI JSON stays byte-identical.
"""

from __future__ import annotations

import random
from typing import Any

from obf.engine import Patch, parse_src, walk_ast

_SPDX_PREFIX = b"// SPDX-License-Identifier:"
_WHITESPACE = b" \t\r\n"
_QUOTES = (0x22, 0x27)  # " and '

_RENAMEABLE_VISIBILITY = frozenset({"private", "internal"})


def _scan_comments_and_whitespace(source: bytes) -> list[Patch]:
    """Return disjoint patches for comments and redundant whitespace.

    Comments and the whitespace around them are treated as one "gap" so a block of
    removed comment lines collapses into a single separator instead of leaving several
    blank lines behind.  Gaps never touch string literals or code tokens.
    """
    patches: list[Patch] = []
    size = len(source)
    gap_start: int | None = None

    def close_gap(end: int) -> None:
        nonlocal gap_start
        if gap_start is None:
            return
        run = source[gap_start:end]
        newlines = run.count(b"\n")
        replacement = b" " if newlines == 0 else b"\n" * min(newlines, 2)
        if replacement != run:
            patches.append((gap_start, end, replacement))
        gap_start = None

    i = 0
    while i < size:
        char = source[i]

        if char in _WHITESPACE:
            if gap_start is None:
                gap_start = i
            i += 1
            continue

        if char == 0x2F and i + 1 < size and source[i + 1] == 0x2F:  # //
            if i == 0 and source.startswith(_SPDX_PREFIX):
                close_gap(i)
                while i < size and source[i] != 0x0A:
                    i += 1
                continue
            if gap_start is None:
                gap_start = i
            i += 2
            while i < size and source[i] != 0x0A:
                i += 1
            continue

        if char == 0x2F and i + 1 < size and source[i + 1] == 0x2A:  # /*
            if gap_start is None:
                gap_start = i
            i += 2
            while i + 1 < size and not (source[i] == 0x2A and source[i + 1] == 0x2F):
                i += 1
            i = min(i + 2, size)
            continue

        if char in _QUOTES:
            close_gap(i)
            quote = char
            i += 1
            while i < size:
                if source[i] == 0x5C:  # backslash escape
                    i += 2
                    continue
                if source[i] == quote:
                    i += 1
                    break
                i += 1
            continue

        close_gap(i)
        i += 1

    close_gap(size)
    return patches


def strip_comments(source_bytes: bytes) -> list[Patch]:
    """Comment removal plus blank-line/indentation compaction."""
    return _scan_comments_and_whitespace(source_bytes)


def _collect_targets(ast: dict) -> dict[int, dict]:
    """Collect declarations that may be renamed without touching the ABI."""
    targets: dict[int, dict] = {}

    def visit(node: dict, ancestors: tuple[dict, ...]) -> None:
        node_type = node.get("nodeType")

        if node_type == "FunctionDefinition":
            name = node.get("name")
            if name and node.get("visibility") in _RENAMEABLE_VISIBILITY:
                targets[node["id"]] = node
            return

        if node_type != "VariableDeclaration" or not node.get("name"):
            return

        parent = ancestors[-1] if ancestors else None
        if parent is None or parent.get("nodeType") in ("ContractDefinition", "SourceUnit"):
            return  # state variable or file-level constant

        if parent.get("nodeType") == "VariableDeclarationStatement":
            targets[node["id"]] = node
            return

        if parent.get("nodeType") == "ParameterList":
            owner = ancestors[-2] if len(ancestors) >= 2 else None
            if (
                owner is not None
                and owner.get("nodeType") == "FunctionDefinition"
                and owner.get("parameters") is parent
                and owner.get("visibility") in _RENAMEABLE_VISIBILITY
            ):
                targets[node["id"]] = node

    walk_ast(ast, visit)
    return targets


def _collect_names(ast: dict) -> set[str]:
    names: set[str] = set()

    def visit(node: dict, _ancestors: tuple[dict, ...]) -> None:
        for key in ("name", "value"):
            value = node.get(key)
            if isinstance(value, str):
                names.add(value)

    walk_ast(ast, visit)
    return names


def _fresh_name(rng: random.Random, used: set[str]) -> str:
    while True:
        candidate = f"_0x{rng.getrandbits(24):06x}"
        if candidate not in used:
            used.add(candidate)
            return candidate


def rename_identifiers(source_bytes: bytes, ast: dict, rng: random.Random) -> list[Patch]:
    """Rename private/internal functions, their parameters and all local variables."""
    targets = _collect_targets(ast)
    if not targets:
        return []

    used = _collect_names(ast)
    mapping: dict[int, str] = {}
    patches: list[Patch] = []

    ordered = sorted(targets, key=lambda decl_id: parse_src(targets[decl_id]["nameLocation"])[0])
    for decl_id in ordered:
        new_name = _fresh_name(rng, used)
        mapping[decl_id] = new_name
        start, end = parse_src(targets[decl_id]["nameLocation"])
        patches.append((start, end, new_name.encode("ascii")))

    def visit(node: dict, _ancestors: tuple[dict, ...]) -> None:
        if node.get("nodeType") != "Identifier":
            return
        decl_id = node.get("referencedDeclaration")
        if decl_id in mapping:
            start, end = parse_src(node["src"])
            patches.append((start, end, mapping[decl_id].encode("ascii")))

    walk_ast(ast, visit)
    return patches


def get_patches(
    source_bytes: bytes,
    ast: dict,
    rng: random.Random,
    **kwargs: Any,
) -> list[Patch]:
    """Level 1 entry point: strip layout noise, then rename private symbols."""
    patches = strip_comments(source_bytes)
    patches.extend(rename_identifiers(source_bytes, ast, rng))
    return patches

class Deployed:

    w3: Web3
    contract: Any
    receipt: Any
    compilation: CompilationResult

        fn = getattr(self.contract.functions, fn_name)(*args)

def _find(ast: dict, node_type: str, predicate=None) -> list[tuple[dict, tuple[dict, ...]]]:
    """Return ``(node, ancestors)`` pairs for every matching AST node."""
    matches: list[tuple[dict, tuple[dict, ...]]] = []

    def visit(node: dict, ancestors: tuple[dict, ...]) -> None:
        if node.get("nodeType") == node_type and (predicate is None or predicate(node)):
            matches.append((node, ancestors))

    walk_ast(ast, visit)
    return matches

def test_pipeline_recompiles_after_each_pass_and_uses_fresh_ast():
    seen_offsets: list[int] = []

    def first_pass(source_bytes, ast, rng, **kwargs):
        # Grow the source *before* the contract so every later offset shifts.
        return [(0, 0, b"// padding comment\n")]

    def second_pass(source_bytes, ast, rng, **kwargs):
        node, _ = _find(ast, "ContractDefinition")[0]
        start, end = parse_src(node["nameLocation"])
        seen_offsets.append(start)
        return [(start, end, b"Shifted")]

    result = run_pipeline(
        SOURCE,
        passes=[PassSpec("pad", first_pass), PassSpec("rename", second_pass)],
        source_name="Smoke.sol",
    )
    assert result.compilation.contract_name == "Shifted"
    assert seen_offsets and seen_offsets[0] == result.source_bytes.index(b"Shifted")

"""Unit and integration tests for the three obfuscation passes (Phase 3).

The heavy functional equivalence proof is the contract suite pointed at each generated
directory (``pytest --contract-dir .../L1``).  These tests pin down the pass-level
guarantees that make those runs meaningful: comments never eat string literals, only
non-ABI symbols are renamed, literals keep their types, ``pure`` functions and
declarations are left alone, and every level keeps the ABI byte-identical.
"""

SYNTH = """// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract Synth {
    uint256 public counter;
    uint8 public small = 5;
    bool public enabled = true;
    bool public disabled = false;
    string public note = "http://example.com//path";

    event Incremented(uint256 value);

    function increment() public returns (uint256) {
        uint256 next = counter + 1;
        counter = next;
        emit Incremented(next);
        return counter;
    }

    function _double(uint256 x) internal pure returns (uint256) {
        return x * 2;
    }

    function _secret(uint256 x) private returns (uint256) {
        uint256 doubled = x * 2;
        return doubled;
    }
}
"""


def _nodes(ast: dict, node_type: str) -> list[dict]:
    found: list[dict] = []

    def visit(node: dict, _ancestors: tuple[dict, ...]) -> None:
        if node.get("nodeType") == node_type:
            found.append(node)

    walk_ast(ast, visit)
    return found


def _spans(ast: dict, node_type: str) -> list[tuple[int, int]]:
    return [parse_src(node["src"]) for node in _nodes(ast, node_type)]

def test_control_skips_pure_functions():
    compiled = compile_source(SYNTH, source_name="Synth.sol")
    data = normalize_source(SYNTH)[1]
    patches = control.get_patches(data, compiled.ast, random.Random(42), max_injections=3)

    pure_bodies = set()
    for function in _nodes(compiled.ast, "FunctionDefinition"):
        if function.get("stateMutability") == "pure" and function.get("body"):
            pure_bodies.add(parse_src(function["body"]["src"]))

    for start, end, _replacement in patches:
        for body_start, body_end in pure_bodies:
            assert not (body_start <= start < body_end)
